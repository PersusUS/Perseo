# Dependencias de perseo-core (Fase A).
#
# Una sola, a propósito. La Fase 3 ya descartó FastAPI + uvicorn por no añadir
# dos dependencias donde bastaba una; aiohttp cubre servidor HTTP, SSE y cliente
# (el router habla con Ollama por HTTP), y pesa poco en una Raspberry Pi, que es
# donde este proceso acabará viviendo.
#
# La cola usa sqlite3, que viene con Python. El router usa Ollama por HTTP, sin
# SDK.

aiohttp>=3.9

# La telemetría de la pantalla de estado: CPU, memoria, disco, red y batería.
# Es la segunda dependencia en cinco fases, y entra porque leer eso en Windows
# sin ella son tres APIs distintas y ninguna portable. Si falta, el núcleo
# arranca igual: `estado.telemetria()` devuelve `disponible: false` y la
# pantalla enseña un hueco en vez de romperse.
psutil>=5.9

# Opcional, y a propósito fuera de la lista: `pyautogui`, que solo necesita el
# agente `pc` para teclear y mover el ratón. Sin ella el núcleo arranca igual,
# abrir aplicaciones y URLs sigue funcionando, y las acciones que la necesitan
# lo dicen. En la Raspberry Pi del plan no hay escritorio donde instalarla.
#
#     pip install pyautogui

# Reconocimiento de personas por voz y cara (biometria). Tambien opcional y
# por el mismo motivo que pyautogui: torch y opencv pesan cientos de megas.
# Sin ellos el nucleo arranca igual y las rutas /biometria dicen que falta.
#
#     pip install -r perseo_core/requirements-biometria.txt

# Y para las pruebas unitarias de `pruebas/`, que tampoco es del nucleo:
#
